# SmartFlow — Procurement Management System

SmartFlow is a modern Procurement Management System designed to streamline and digitize organizational procurement workflows.

The application helps organizations manage purchase requests, approval workflows, suppliers, purchase orders, budgets, and audit activities through a centralized and user-friendly platform.

## Features

- Create and manage purchase requests
- Track procurement approval workflows
- Manage suppliers
- Create and monitor purchase orders
- Track departmental budgets
- Maintain procurement audit logs
- Centralized procurement dashboard
- Modern and responsive user interface

## Technology

- Google App Builder
- Android
- Kotlin
- Gradle
- MongoDB Atlas
- GitHub

## Project Objective

SmartFlow aims to reduce manual procurement processes, improve workflow transparency, provide better budget visibility, and make procurement operations more efficient.
